파이썬으로 탐구하는 SOLID 원칙

개념기반탐구학습지 · 3차시(차시당 45~50분). 설명을 읽는 수업이 아니라, 예측하고 · 실행하고 · 분류하고 · 토론하고 · 직접 규칙을 말해 보는 수업입니다.

이 자료는

  • 대상: 파이썬 클래스(class, __init__, 메서드, 상속)를 써 본 학습자
  • 환경: Python 3.10 이상, 표준 라이브러리만 사용. 인터넷 없이 동작합니다.
  • 학습지 사용법: 입력칸에 쓰면 이 브라우저에 자동 저장됩니다. 인쇄(PDF)도 가능합니다. 정답은 학습지에 없습니다. 먼저 스스로 써 보세요.

3차시 탐구학습지

  • 1차시. 변경에 강한 코드
    렌즈: 변경 · SRP, OCP · 카페 주문과 할인 정책
  • 2차시. 코드 사이의 약속
    렌즈: 약속 · LSP, ISP · 새와 펭귄, 복합기
  • 3차시. 의존의 방향과 설계 프로젝트
    렌즈: 의존 · DIP, 종합 · 알림 서비스, 도서관 대출

사전 읽기·참고 (교재형 자료)

학습지 활동을 하다가 개념이 더 필요하면 참고하세요. 수업 전에는 0장(OOP 복습)을 읽어 오면 좋습니다.

  • 1장. SRP
