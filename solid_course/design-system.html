디자인 시스템

파이썬 SOLID 수업자료 전체(학습지·교재·평가·교사용 문서)가 같은 규칙으로 보이도록, 색·글자·간격·모서리·그림자를 토큰으로 정의하고 컴포넌트가 토큰만 쓰게 한 약속입니다. 목표는 가독성(긴 글과 코드를 편하게 읽기), 절제된 품격(종이 질감의 바탕, 남색 하나의 강조색), 일관성(같은 역할은 같은 모양)입니다.

설계 원칙

1 · 읽기 먼저

본문 16px·줄 간격 1.78, 한 줄 약 62자 이내, 한글 어절 단위 줄바꿈(word-break: keep-all). 장식보다 위계(크기·굵기·여백)로 구분합니다.

2 · 색은 의미로만

남색은 "행동·강조", 초록은 "맞음·관찰", 빨강은 "위험·논쟁", 금색은 "예측·주의"에만 씁니다. 장식용 색은 만들지 않습니다.

3 · 토큰만 사용

컴포넌트 CSS에 #hex·임의 px를 쓰지 않고 var(--…)만 씁니다. 다크 모드와 인쇄가 토큰 교체로 자동 해결됩니다.

4 · 접근성

본문 대비 4.5:1 이상, 키보드 초점 링(:focus-visible), 움직임 줄이기(prefers-reduced-motion), 색만으로 의미를 전달하지 않기(배지에 글자).

사용 규칙

✓ 해야 할 것

  • 새 컴포넌트는 assets/style.css(공통) 또는 worksheet.css(학습지)에 토큰만으로 추가
  • 같은 역할은 같은 클래스 — 새 이름을 만들기 전에 위 컴포넌트를 먼저 재사용
  • 다크 모드·인쇄 화면에서 한 번씩 확인
  • 색만이 아니라 글자·아이콘을 함께 사용

✗ 하지 말 것

  • 컴포넌트에 #hex, 임의 px·rem 직접 쓰기
  • 활동 유형 색을 장식 목적으로 다른 곳에 쓰기
  • 한 화면에 채워진(주) 버튼 둘 이상
  • --warn(진한 경고색)과 --warn-soft(연한 면)를 혼동
